Start→ Stay up→ Receive traffic→ Reach dependencies
1 Start
Symptoms
ImagePullBackOff ErrImagePull RunContainerError Pending
Causes
Wrong image name or tag, bad registry creds, bad command/args, missing ConfigMap or Secret, insufficient CPU/memory, node affinity or taint
First checks
kubectl describe pod <name>
kubectl get events
kubectl logs <name>
2 Stay up
Symptoms
CrashLoopBackOff OOMKilled Restarting 0/1 Ready
Causes
App crashes on startup, OOM from low memory limit, failing liveness or readiness probe, missing env var or dependency at boot
First checks
kubectl logs <name> --previous
kubectl describe pod <name>
kubectl top pod <name>
3 Receive traffic
Symptoms
503 / 502 Connection refused No endpoints
Causes
Service selector doesn't match pod labels, wrong targetPort or containerPort, readiness probe failing, Ingress backend misconfigured, wrong host or path rule
First checks
kubectl get endpoints <svc>
kubectl describe svc <name>
kubectl describe ingress
kubectl port-forward <pod>
4 Reach deps
Symptoms
Connection timeout Auth errors DNS failures 403 Forbidden
Causes
Bad DB credentials in secret, DNS not resolving, NetworkPolicy blocking egress, RBAC missing, storage PVC not bound, external API unreachable
First checks
kubectl logs <name>
kubectl exec -- nslookup <host>
kubectl get networkpolicy
kubectl auth can-i ...
